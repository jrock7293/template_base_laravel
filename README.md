# template_laravel
Template Base para desarrollar en Laravel

# El template incluye:
- Brezze (Para autenticacion)
- Bootstrap (Para los estilos y maquetacion)

La plantilla no esta con ningun framework de Frontend

# Para la configuracion inicial luego de clonarlo:
### Instalamos paquetes y dependencias de composer
composer install

### Generamos la key de la app
php artisan key:generate

### Ejecutar migraciones
php artisan migrate

### Ejecutar servidor
php artisan serve

### corremos el front
npm install y npm run dev
